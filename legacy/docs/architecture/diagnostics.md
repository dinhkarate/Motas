# Sanitized diagnostics export

Motas can build a support report from normalized state without exporting credentials or raw connector responses.

## Contents

- Motas schema/app version;
- current readiness state/title/source;
- provider health, quality and normalized quota summaries;
- proxy health, quality, route and account-count summaries;
- redacted endpoint labels;
- enabled/source metadata;
- bounded local history;
- sanitized configuration/storage issues.

## Excluded data

Reports never contain:

- Keychain values;
- secure-field input;
- endpoint paths, query strings or userinfo;
- account emails;
- cookies or authorization headers;
- Claude transcripts/session paths;
- raw connector response bodies;
- raw observation messages.

Both JSON and Markdown formats are generated by the pure Core `DiagnosticReportBuilder`, so privacy tests do not depend on the SwiftUI app.

## Reset behavior

The Settings Diagnostics section can remove Motas-owned data after confirmation:

- `settings.json`;
- `history.json`;
- fallback/App Group snapshots;
- Motas's four proxy Keychain entries.

It deliberately does not remove Claude Code's status-line cache or any third-party service data.

Diagnostics generation/copy/save failure does not affect live readiness refresh.
