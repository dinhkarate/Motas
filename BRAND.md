# Motas Brand Notes

## Brand name

**Motas**

## Meaning

**Motas = Mac + Quota**

Motas is the brand name for a Mac-first tool focused on quota, usage, limits, and resource visibility.

## Positioning

Motas should feel like a lightweight, native, practical Mac utility for people who need to understand and control usage limits.

Potential product directions:

- Mac quota monitor
- API/token usage tracker
- AI model quota dashboard
- Local usage and limit observer
- Developer productivity utility for macOS

## Short description

**Motas is a Mac-first quota and proxy health monitor for AI coding stacks.**

## Tagline options

- **Motas — Mac quota, made clear.**
- **Motas — Quota tracking for your Mac.**
- **Motas — Keep your Mac quotas in check.**
- **Motas — Monitor usage, limits, and tokens.**
- **Motas — Usage clarity for Mac power users.**

Recommended initial tagline:

> **Motas — Mac quota, made clear.**

## Naming usage

Use **Motas** as the primary brand name.

Avoid writing it as:

- MOTAS
- MoTas
- MacQuota
- MotaS

Acceptable product/package usage:

- App name: `Motas`
- CLI binary: `motas`
- Homebrew package/cask: `motas`
- Bundle identifier suggestion: `dev.motas.app` or `com.yourcompany.motas`

## Brand tone

Motas should sound:

- Clear
- Calm
- Native
- Practical
- Developer-friendly
- Minimal but useful

Avoid sounding:

- Enterprise-heavy
- Overly technical for basic users
- Crypto/finance-like despite the word “quota”
- Too generic like a system settings clone

## One-liner

> **Motas helps Mac users see AI quota and proxy health before coding sessions break.**

## Longer description

Motas is a macOS utility designed to make AI quota and proxy health visible. Whether tracking Claude, Codex, Gemini, Antigravity, OpenRouter, 9Router, CLIProxyAPI, ProxyPal, or custom OpenAI-compatible proxies, Motas gives Mac users a simple way to see remaining capacity, fallback readiness, and stack health before coding sessions are interrupted.

## Brand decision

We will use **Motas** as the official brand for this project.

Decision rationale:

1. Short and memorable.
2. Derived from **Mac + Quota**.
3. More brandable than the literal name `MacQuota`.
4. Suitable for a Mac utility or developer-focused app.
5. Flexible enough to expand into future products such as Motas Cloud, Motas Agent, or Motas Studio.
